# Global Behavioral Rules

1. **Never commit directly to or target the `main` branch.** All pull requests and new features must be targeted against the `dev` branch.
2. **Hold before executing:** Do not autonomously execute commands or tool calls for modifying PRs or pushing code immediately after a user says "yes" without double-checking the exact parameters with the user.
3. **Simple Commits and PRs:** Keep PR descriptions clean, professional, and free of unnecessary emojis or overly complex diagrams unless requested. Keep commit messages plain and conventional.
